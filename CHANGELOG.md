## [0.2-beta] - 2026-10-31

This second beta completes the foundation of the collaborative IVENA statistics platform. On top of the allocation statistics of v0.1-beta it adds a second data source: IVENA closure lists are imported and analysed as closure analytics with profiles, volume projections and constellations, and closed-department metrics reach the monthly reports. Statistics gain Insights across catalog dimensions, a guided analysis assistant, Top List exports and comparisons, and maps for allocation orientation, isochrone origins and dispatch area catchments.

Operations got a monitoring baseline: storage monitoring with capacity alerts, run summaries and alerts for background jobs, Messenger monitoring, and a multi-channel notification system. Imports can be reprocessed, handled in bulk and show their data coverage. The reference catalog is now portable, so the repository holds no curated data, and a synthetic data generator with an offline demo environment makes the platform presentable without real hospital data. Under the hood the UI was consolidated into shared components (DataTable, filters, modals, mobile cards), all code reads time from the Symfony clock, a pre-release security audit and consistency review tightened access checks and removed dead code, and CI, tests and agent instructions were tightened.

Existing installations: follow the [upgrade guide](docs/05-operations/upgrading.md#v01-beta--v02-beta) for configuration changes and one-time commands after the deploy.
